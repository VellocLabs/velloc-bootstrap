# Building the Velloc client

The build guide lives with the code it builds:
**[velloc-core → Build the Velloc client](https://github.com/VellocLabs/velloc-core#build-the-velloc-client)**.

Most people never need it: install a released client from the
[Releases page](https://github.com/VellocLabs/velloc-bootstrap/releases/latest)
and develop the [runtime](README.md#develop-the-runtime) against it.
